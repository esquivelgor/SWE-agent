# Python Object-Oriented Identifier
## Dependencies
You can create a venv and install the dependencies from the **requirements.txt**
``` bash
python -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

## Steps to run
To run the parser over an already pre-established set of files, run
```
python tester.py
```
Alternatively, to try the parser on a single file of your own choosing, add the file to the root directory and run
```
python runner.py <your_file.txt>
```
